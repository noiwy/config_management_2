# Анализатор графа зависимостей Cargo

## 1. Общее описание
CLI-инструмент для визуализации графа зависимостей менеджера пакетов Rust (Cargo). Программа получает транзитивные зависимости пакета с помощью алгоритма поиска в ширину (BFS) с использованием рекурсии. Поддерживается обработка циклических зависимостей, вывод порядка загрузки пакетов, генерация кода для диаграмм D2 и вывод результата в формате ASCII-дерева. Сторонние библиотеки и менеджеры пакетов для анализа не используются.

## 2. Описание функций и настроек
Все настраиваемые параметры передаются через аргументы командной строки.

**Настройки (аргументы CLI):**
* `package` — имя анализируемого пакета (обязательный позиционный аргумент).
* `--repo` — URL-адрес репозитория (API crates.io) или путь к локальному JSON-файлу (обязательный параметр).
* `--version` — версия пакета (обязательный параметр).
* `--test-mode` — включение тестового режима для чтения графа из локального файла.
* `--ascii` — флаг для дополнительного вывода графа в формате визуального ASCII-дерева.

**Основные функции кода:**
* `get_arg_parser()` — настройка и валидация аргументов командной строки.
* `get_direct_deps()` / `get_test_deps()` — функции получения прямых зависимостей через сетевой HTTP-запрос или из локального файла-заглушки.
* `bfs_recursive()` — рекурсивный обход графа (BFS). Собирает зависимости, формирует порядок загрузки и предотвращает бесконечные циклы с помощью множества `visited`.
* `print_d2_graph()` — формирование и вывод связей графа в формате языка диаграмм D2.
* `print_ascii_tree()` — рекурсивная функция для красивого вывода дерева в консоль.

## 3. Команды для сборки проекта и запуска
Проект написан на языке Python с использованием исключительно стандартной библиотеки. Дополнительная сборка или установка зависимостей (pip install) не требуется.

Запуск через интерпретатор Python:
`python src/main.py [аргументы]`

Запуск через скрипт (Windows):
`run.bat [аргументы]`

## 4. Примеры использования

**Пример 1: Анализ реального пакета serde с выводом ASCII-дерева**
`python src/main.py serde --repo https://crates.io/api/v1/crates --version 1.0.136 --ascii`

**Пример 2: Запуск в тестовом режиме для проверки циклических зависимостей**
`python src/main.py A --repo tests/test_graph.json --version 1.0 --test-mode`
